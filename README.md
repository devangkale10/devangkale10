`Python` `LangChain` `ChromaDB` `LangSmith` `Streamlit` `Docker` `CI/CD`

### 🎓 Predictive Analytics for Student Success
Models how Student Life services relate to retention and graduation, to inform leadership decisions on program investment.
- **How:** feature engineering on student engagement and academic records, predictive ML models in Python, and Snowflake SQL (CTEs, window functions) for multi-year retention and graduation rates by program participation
- **Result:** KPIs that power leadership dashboards on student outcomes

`Python` `scikit-learn` `Feature Engineering` `Snowflake` `SQL`

### 📚 LLM-Powered Data Dictionary
A semantic metadata layer for current and future AI applications, generating data definitions and profiles across the Snowflake warehouse.
- **How:** Gemma 4 through LiteLLM and UF's NaviGator API gateway, with a human review step for the columns that most need checking
- **Result:** replaced manual data documentation and grounds the RAG assistant above

`Gemma 4` `LiteLLM` `Snowflake` `Python` `Human-in-the-Loop`


### 🔄 Data Pipelines, Automation & Dashboards
The data foundation behind Student Life reporting.
- **ELT:** incremental pipelines in Python and dbt that ingest data from third-party vendor APIs into Snowflake, with dbt tests and email alerts on failure, building data marts for the food pantry, RecSports, and other dashboards
- **Automation:** student eligibility checks and GPA reporting for Student Life offices, built with Python, Streamlit, DuckDB, and Snowflake
- **Dashboards:** Power BI and Tableau reporting on student success, enrollment, and campus engagement, built on Snowflake star-schema models with reusable DAX measures and scheduled refresh

`Python` `dbt` `Snowflake` `DuckDB` `Streamlit` `Power BI` `Tableau`
